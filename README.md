# Hangman Game Using Python

## About the Project

This project is a simple text-based Hangman game developed using Python. It is a one-player game in which the computer randomly selects a secret word, and the player tries to guess the word one letter at a time.

## Features

- Random word selection
- Interactive text-based gameplay
- ASCII Hangman drawing displayed in the terminal
- Six incorrect guesses allowed
- Letter validation
- Prevents repeated guesses
- Win and loss detection
- Score tracking
- Option to play again

## Technologies Used

- Python
- Random module
- Conditional statements
- Loops
- Lists and strings
- Functions

## How to Run the Project

1. Install Python on your computer.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Execute the following command:

```bash
python hangman.py
```

## How to Play

1. Run the Python program.
2. The computer selects a random word.
3. Guess one alphabet letter at a time.
4. Correct guesses reveal letters in the hidden word.
5. Incorrect guesses gradually complete the Hangman drawing.
6. Guess the complete word before using all six incorrect attempts to win.
